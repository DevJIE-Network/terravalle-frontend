# TerraValle — Frontend

Plataforma web progresiva (PWA) de bienes raíces que permite publicar inmuebles mediante **fichas técnicas estandarizadas** y obtener una **estimación orientativa de precio asistida por IA**.

> Proyecto académico de la materia **Programación de Aplicaciones Web Progresivas** — Universidad Tecnológica de Tula-Tepeji (UTTT).

---

## Descripción

Este repositorio contiene la interfaz de usuario de TerraValle. Se comunica con el backend del proyecto, que se encuentra en un repositorio independiente: [terravalle-backend](https://github.com/DevJIE-Network/terravalle-backend).

## Funcionalidades principales (MVP)

- Registro e inicio de sesión de usuarios.
- Publicación de inmuebles mediante ficha técnica.
- Estimación orientativa de precio con IA.
- Catálogo con búsqueda y filtros.
- Detalle del inmueble con información de su entorno.

## Estado del proyecto

🚧 **En desarrollo.** La estructura, tecnologías e instrucciones de instalación se documentarán conforme avance el proyecto.

## Metodología

El proyecto se gestiona con **Scrum** en Jira, organizado en sprints semanales.

Ramas:

- `main` → versión estable
- `develop` → integración
- `feature/nombre-tarea` → desarrollo de cada historia de usuario
